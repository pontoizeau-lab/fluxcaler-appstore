# Fluxcaler Analytics (Umami)

Mesure d'audience **sans cookies** de vos sites : visites, pages vues, sources, pays, appareils et événements.

- Installé **sur votre serveur** par Fluxcaler : les données de vos visiteurs ne le quittent pas.
- Aucun cookie, aucune adresse IP conservée.
- Mis en place et piloté par Max ; vos chiffres sont présentés dans votre tableau de bord (Metabase).
- Seuls le script de mesure et l'adresse d'envoi des visites sont publics ; l'interface d'administration ne l'est pas.

Logiciel : [Umami](https://umami.is) (open source, licence MIT), version 3.4.1.
